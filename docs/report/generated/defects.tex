\subsubsection{DEF-01 – login CSRF}
- \textbf{Kroki:} \texttt{POST /user/login} z nagłówkami \texttt{Origin: http://evil.example}, \texttt{Sec-Fetch-Site: cross-site} i poprawnymi danymi.

- \textbf{Oczekiwany rezultat:} odrzucenie żądania (403), tak jak dla innych akcji zmieniających stan (\texttt{/repo/create} zwraca 403).

- \textbf{Rzeczywisty rezultat:} \texttt{303 -> /}, ustawiona sesja zalogowanego użytkownika.

- \textbf{Wpływ:} atakujący może zalogować ofiarę na swoje konto (session fixation / login CSRF).

- \textbf{Automatyzacja:} \texttt{tests/nonfunctional/test\_quality.py::TestSecurity::test\_cross\_origin\_login\_is\_rejected} (\texttt{xfail strict}).
